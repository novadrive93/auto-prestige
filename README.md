# Auto Prestige 🚗

Site web premium pour une concession automobile de luxe.

## 📋 Description

Auto Prestige est un site web moderne et élégant conçu pour présenter une sélection de véhicules haut de gamme. Le design utilise un schéma de couleurs noir et or pour un look premium.

## ✨ Caractéristiques

- **Navigation fixe** avec effet blur
- **Section héros** avec image de fond impressionnante
- **Grille de véhicules** responsive avec cartes interactives
- **Section "Pourquoi nous"** avec 4 avantages clés
- **Avis clients** avec étoiles
- **Appel à l'action** avec contact WhatsApp
- **Design mobile-friendly** avec media queries
- **Animations smooth** et transitions fluides

## 🎨 Couleurs

- **Or**: `#d4af37` (accent premium)
- **Noir**: `#0b0b0b` (fond principal)
- **Gris foncé**: `#121212` (cartes)

## 📱 Responsive

Le site est optimisé pour:
- 📺 Desktop
- 💻 Tablette
- 📱 Mobile

## 🚀 Déploiement

### Option 1: GitHub Pages
1. Active GitHub Pages dans les paramètres du repo
2. Sélectionne `main` comme branche source
3. Accède à: `https://novadrive93.github.io/auto-prestige`

### Option 2: Vercel/Netlify
- Connecte ton repo à Vercel ou Netlify
- Déploiement automatique à chaque push

### Option 3: Hébergement traditionnel
- Télécharge le fichier `index.html`
- Upload sur ton serveur FTP

## 🔧 Personnalisation

### Changer le numéro WhatsApp
Modifie cette ligne dans `index.html`:
```html
<a href="https://wa.me/33600000000" class="btn btn-primary">
```
Remplace `33600000000` par ton numéro.

### Ajouter/modifier des véhicules
Copie et adapte une section `.car-card`:
```html
<div class="car-card">
  <img src="URL_IMAGE">
  <div class="car-info">
    <h3>Modèle</h3>
    <div class="price">Prix</div>
    <div class="details">Détails</div>
    <a href="#" class="card-btn">Voir le véhicule</a>
  </div>
</div>
```
